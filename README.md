# YtonGame-HostingMenu

一款 Minecraft Forge Mod，在游戏内集成服务器托管套餐展示功能。

## 功能特性

- 在创建世界界面新增 **Hosting** 标签页
- 展示多种服务器托管套餐（入门型、标准型、灵活型、悦享型、曜石型）
- 支持远程动态加载套餐数据，本地 JSON 作为后备
- 一键跳转购买页面

## 环境要求

- Minecraft 1.20.1
- Forge 47.4.0+
- Java 17

## 安装方法

1. 确保已安装对应版本的 Forge
2. 将 Mod 文件放入 `.minecraft/mods` 目录
3. 启动游戏即可
