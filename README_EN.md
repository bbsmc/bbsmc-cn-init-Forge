# YtonGame-HostingMenu

A Minecraft Forge Mod that integrates server hosting package display within the game.

## Features

- Adds a **Hosting** tab to the Create World screen
- Displays multiple server hosting plans (Starter, Standard, Flexible, Premium, Obsidian)
- Supports remote dynamic package data loading with local JSON fallback
- One-click redirect to purchase page

## Requirements

- Minecraft 1.20.1
- Forge 47.4.0+
- Java 17

## Installation

1. Ensure the corresponding version of Forge is installed
2. Place the Mod file into the `.minecraft/mods` directory
3. Launch the game
